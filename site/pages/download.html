Homebrew

Recommended. Homebrew keeps aituner up to date with brew upgrade.

$ brew install --cask tonynv/tap/aituner

Disk image

Open it and drag aituner to Applications. aituner then keeps itself up to date, and asks first.

Download .dmg .zip

Requirements

An Apple Silicon Mac (M1 or later) with macOS 14 or later. 16 GB of memory or more is recommended for useful coding models; aituner shows what fits yours.

Verify the download

Each release lists SHA-256 checksums in SHA256SUMS, and the app is signed and notarized: spctl --assess -v /Applications/aituner.app should say "accepted".

What's new

Every release has notes on GitHub. Read the release notes.
